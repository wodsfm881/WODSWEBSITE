# WODS FM 88.1 Website

Official website project for WODS FM 88.1 in Big Rapids, Michigan.

**MUSIC • NEWS • COMMUNITY**

This repository contains the station's responsive static website and is structured for straightforward deployment to Vercel.

## Development

Open `index.html` locally in a browser, or deploy the repository as a static site.

## Listen Live

The site includes a Listen Live interface. Add the station's confirmed streaming URL in `script.js` before enabling playback.
